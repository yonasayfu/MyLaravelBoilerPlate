# LaraveleBoilerPlate# Laravel Boilerplate Platform

## Project Overview

This is a comprehensive Laravel boilerplate application that implements clean architecture principles with performance optimization features. The boilerplate includes:

- **Staff/User based controller access**
- **Global search functionality**
- **Messaging system**
- **Notification system**
- **Toast notifications**
- **CRUD operations with pagination, sorting, export, and download capabilities**
- **RESTful API layer**
- **Mobile integration ready**
- **Redis caching for performance optimization**

## Technologies Used

*   **Backend**: Laravel (PHP 8.1+)
*   **Frontend**: Vue.js (TypeScript) with Inertia.js
*   **Build Tool**: Vite
*   **Database**: PostgreSQL
*   **Caching**: Redis
*   **Testing Framework**: PHPUnit
*   **Authentication**: Laravel Breeze with Inertia

## Key Features Implemented

### Architecture
- Clean Architecture implementation with clear separation of concerns
- Base controllers, services, and DTOs for consistent development patterns
- Performance optimized components with Redis caching
- Comprehensive error handling with custom exception hierarchy

### User & Staff Management
- Complete CRUD operations for users and staff
- Role-based access control (RBAC) with Spatie Permissions
- User profile management
- Phone number and profile photo support

### API Layer
- Versioned RESTful API (v1)
- Standardized JSON responses
- Pagination and sorting support
- Rate limiting capabilities

### Performance Optimization
- Redis caching for database queries
- Object pooling for DTOs to reduce memory allocation
- Cached dropdown services for frequently accessed data
- Query optimization in services

### Frontend Integration
- Inertia.js for SPA-like experience
- Vue.js components with TypeScript
- Toast notification system
- Responsive design for mobile compatibility

## Development Standards & Principles

*   **Clean Architecture**: Controllers → Services → Models pattern
*   **DTO Pattern**: Data Transfer Objects for type safety and validation
*   **Caching**: Redis caching for performance-critical operations
*   **Testing**: Comprehensive test coverage for all components
*   **Code Style**: PSR-12 compliance with Laravel Pint
*   **Security**: Input validation, authorization checks, secure coding practices

## Getting Started

1. Clone the repository
2. Install PHP dependencies: `composer install`
3. Install Node dependencies: `npm install`
4. Copy `.env.example` to `.env` and configure your environment
5. Generate application key: `php artisan key:generate`
6. Run database migrations: `php artisan migrate`
7. Start the development server: `npm run dev`

## Build Commands

## Key Components

- `OptimizedBaseController` - Performance enhanced web controller
- `BaseApiController` - Standardized API responses
- `BaseService` - Common service functionality
- `PerformanceOptimizedBaseService` - Caching-enabled service
- `BaseDTO` - Data Transfer Object with object pooling

### Core Services
- `UserService` - User management with caching
- `CachedDropdownService` - Optimized dropdown data
- `BaseValidationRules` - Common validation patterns

### Exception Handling
- `BaseException` - Foundation for all custom exceptions
- `ValidationException` - Data validation errors
- `AuthorizationException` - Access control violations
- `BusinessException` - Business rule violations
- `ServiceException` - Service-level errors
