## 📋 **SYSTEM OVERVIEW**

### **Technology Stack**
- **Backend**: Laravel 10+ PHP 8.1+
- **Frontend**: Vue 3 + TypeScript + Inertia.js
- **Styling**: Tailwind CSS
- **Database**: PostgreSQL (Primary)
- **Cache**: Redis
- **Queue**: Redis (Background Jobs)
- **Real-time**: Laravel Echo + WebSockets
