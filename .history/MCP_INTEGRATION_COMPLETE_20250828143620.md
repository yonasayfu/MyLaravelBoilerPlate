4. `get_boilerplate_statistics` - Get project info

## 🚀 How to Use It

### Start the MCP Server:
```bash
php artisan boost:mcp
```

### Connect AI Assistants:
- **Claude Desktop**: Add as MCP server at `http://localhost:8090`
- **Cursor IDE**: Configure MCP in settings
- **Other AI tools**: Point to `http://localhost:8090`

### Example AI Queries:
- "What models are in this boilerplate?"
- "Analyze the architecture compliance"
- "Show me the database schema"
- "What Laravel version is this using?"
